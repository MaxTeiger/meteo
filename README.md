# Météo (toujours beau)

Application météo qui affiche **toujours** du beau temps, quoi qu'il arrive : 22 à 26 °C, soleil, zéro pluie.
Les valeurs sont inventées (stables pour une même ville et un même jour). Seuls le nom de la ville
(recherche Open-Meteo Geocoding, ou géolocalisation + BigDataCloud) sont réels.

Fichier unique `index.html`, servi par GitHub Pages sur https://meteo.maxteiger.com.
